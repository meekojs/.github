<h1 align="center">Meeko</h1>

<p align="center">Componentes para TypeScript, inspirados en una gatita muy especial.</p>

<p align="center">

---

Meeko es un motor experimental de componentes para TypeScript. Los archivos `.meeko` reúnen lógica tipada, plantilla y estilos en un solo lugar.

El proyecto explora una forma de construir interfaces con:

- **TypeScript** para expresar la lógica y los contratos de los componentes.
- **Renderizado en servidor (SSR)** para generar el HTML inicial.
- **Hidratación** para conectar la interacción al HTML existente.
- **Reactividad por señales** para actualizar la interfaz cuando cambia el estado.

### Una carita, una historia 🐾

Este proyecto nació en honor a mi gatita **Meeko**. Su nombre y su carita forman parte de su identidad: los ojos azules, las orejitas oscuras y la mancha blanca del centro inspiran el logo.

### Estado del proyecto

Meeko está en una etapa temprana y experimental. Su sintaxis y sus API pueden cambiar antes de una primera versión estable. El repositorio público se está preparando.

Puedes seguir el proyecto en **[meekojs/meeko](https://github.com/meekojs/meeko)**.
